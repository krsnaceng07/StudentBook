## Overview

StudentSociety is a monorepo platform connecting students and colleges. It consists of a mobile application built with React Native (Expo) and a backend REST/WebSocket API built with Node.js (Express & TypeScript). ## Data Flow

1. **Client Interaction:** Users interact with the React Native mobile app. Local state is managed via Zustand.
2. **API Communication:** The mobile app sends REST HTTP requests (via axios/fetch) or WebSocket messages to the backend API.
3. **Authentication & Persistence:** The backend validates requests (often using JWTs via Supabase), executes business logic, and interacts with the Supabase PostgreSQL database. Media files are uploaded to Cloudinary.
4. **Real-time Updates:** Real-time events (like messaging) are pushed to the client via Socket.io.
